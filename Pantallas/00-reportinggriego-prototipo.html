Configuración

Ajustes globales · los cambios por sitio se gestionan en cada ficha de sitio

Notificaciones de fallo
Aviso automático por email cuando una fuente de datos falla tras los reintentos (FR-011)
Activo
Notificaciones activadas
Cuando está activo, se envía un email al detectar un fallo irrecuperable en cualquier fuente del proceso mensual.
Destinatarios
Uno o más emails separados por coma o Intro. Se notifica a todos cuando se dispara un aviso.
antonio@elgriego.net
soporte@elgriego.net
Eventos que disparan el aviso
Elige qué situaciones generan un email automático.
Verificar configuración
Envía un email de prueba a todos los destinatarios para confirmar que la entrega funciona.
Enviado
Servidor de correo (SMTP)
Credenciales del servidor usado para enviar notificaciones · se aplica a todos los sitios
Verificado
Para Gmail, usa una contraseña de aplicación de Google en lugar de tu contraseña principal. Actívala en Cuenta Google → Seguridad → Verificación en dos pasos → Contraseñas de aplicaciones.
Servidor SMTP
Host y puerto del servidor saliente.
Usuario
Cuenta de correo desde la que se envían los avisos.
Contraseña / App password
Almacenada de forma cifrada en el sistema de claves del OS.
Cifrado
Protocolo de seguridad de la conexión SMTP.
Comportamiento de reintentos
Cuántas veces y con qué espera se reintenta una fuente antes de marcarla como fallida (FR-011)
Número máximo de reintentos
Por defecto 3. Tras agotar los intentos, la fuente se marca como fallida y el proceso continúa.
intentos
Espera entre reintentos
Segundos de pausa entre cada intento. Un valor mayor reduce la carga sobre la fuente.
segundos
Credenciales globales
Claves API compartidas por todos los sitios · las credenciales por sitio se gestionan en cada ficha
Las claves API se guardan cifradas con el llavero del sistema operativo. Nunca se escriben en texto plano en el disco.
Google API Key
Usada para consultar PageSpeed Insights API y Google Search Console API. Crea una en Google Cloud Console con los permisos necesarios.
OAuth 2.0 Client ID
ID de cliente OAuth de Google para autorizar el acceso a Search Console y Site Kit en nombre de la cuenta del gestor.
OAuth 2.0 Client Secret
Secret asociado al Client ID anterior. Obtened ambos en Google Cloud Console → Credenciales.
Exportación automática
Carpeta de destino y formato para los archivos CSV y capturas que genera cada informe
Carpeta de exportación
Ruta local donde se guardan los CSV y las capturas de pantalla. Debe existir antes de generar el primer informe.
Exportar CSV al completar informe
Genera automáticamente el CSV de métricas en la carpeta de exportación cuando el informe finaliza.
Separador de campos CSV
Punto y coma recomendado para compatibilidad con Excel en configuraciones de idioma español.
Zona de peligro
Acciones irreversibles · no se puede deshacer
Restablecer configuración
Elimina toda la configuración global y vuelve a los valores por defecto. Los sitios y el histórico no se ven afectados.
Eliminar todos los registros históricos
Borra permanentemente el histórico de todos los sitios. Las capturas no se eliminan del disco.
