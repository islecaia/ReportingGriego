?¿Cómo funciona esta pantalla?

Aquí gestionas todos los sitios web que monitoriza la herramienta.

  1. Añadir sitio: pulsa "Añadir sitio", introduce la URL y guarda.
  2. Configurar fuentes: haz clic en el botón de edición de un sitio para configurar las credenciales de cada fuente (Google Search Console, GA4, Squirrly, PageSpeed, Security Ninja).
  3. Indicadores de fuentes: los puntos de colores en la columna "Fuentes" muestran qué fuentes están activas para ese sitio (verde = configurada, rojo = sin configurar).
  4. Una vez configuradas las fuentes, ve a Generar informe para extraer los datos del mes.
